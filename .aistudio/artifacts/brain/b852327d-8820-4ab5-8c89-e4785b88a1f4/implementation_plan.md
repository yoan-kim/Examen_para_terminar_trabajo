# 오답 노트 팝업 안내 문구 및 실전 시험 '재시험' 버튼 추가 계획

실전 시험 종료 후 자동으로 열리는 **오답 노트 팝업** 하단에 직관적인 닫기 안내 문구를 추가하고, 시험 응시 도중 언제든 새로운 무작위 문제로 1번부터 즉시 다시 시작할 수 있는 **'재시험'** 버튼을 시험 화면 오른쪽 아래에 배치합니다.

### User Review & Critical Decisions

> [!IMPORTANT]
> 아래 확정된 동작 방식을 기준으로 구현을 진행합니다.

- **오답 노트 팝업 하단 안내 문구**: 팝업창 가장 아래(푸터 영역)에 `"오답공부가 필요 없다면 "닫기" 버튼을 누르시면 됩니다"` 공지 문구를 명확하게 표시합니다.
- **실전 시험 중 '재시험' 버튼 동작 (확정)**: 시험 진행 화면 오른쪽 아래에 **`재시험`** 버튼을 배치하며, 클릭 시 별도의 확인 창 없이 **즉시 새로운 무작위 문제를 생성하여 1번 문제부터 다시 시작**합니다.

---

### 1. Overview & Core Concept

- **What It Does**:
  1. 실전 시험의 마지막 문제 정답 확인 후 오답 노트 팝업이 열렸을 때, 사용자가 당장 오답 복습을 원치 않는 경우 바로 창을 닫고 점수 결과 화면으로 이동할 수 있도록 하단에 친절한 공지 문구를 제공합니다.
  2. 실전 시험을 치르는 도중 초반에 실수가 많거나 처음부터 다시 응시하고 싶을 때, 오른쪽 아래의 **`재시험`** 버튼 하나로 즉시 시험을 리셋하고 1번부터 새로 응시할 수 있게 합니다.
- **Target Audience / Persona**: 퇴근 전 스페인어 600단어를 빠르게 테스트하고 반복 응시하며 80점 이상 합격을 목표로 하는 학습자.
- **Key Value**: 불필요한 클릭이나 화면 이탈 없이 시험 재응시와 오답 복습 여부를 즉각 결정할 수 있는 빠른 학습 흐름 제공.

---

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **실전 시험 진행 중 (`ExamView` - Playing 단계)**:
     - 문제 풀이 영역 하단 우측에 **`재시험`** 버튼(회전 아이콘 포함)이 항상 배치됩니다.
     - 답변 제출 전에는 우측 하단에 단독(또는 제출 버튼 아래 우측 정렬)으로 표시되며, 답변 확인 후에는 좌측의 **`다음 문제 (Enter)`** 버튼과 나란히 오른쪽 아래에 배치됩니다.
     - **`재시험`** 버튼을 누르면 즉시 점수·오답 기록이 초기화되고, 새로운 무작위 문제 세트로 1번 문항부터 시험이 다시 시작됩니다.
  2. **오답 노트 팝업 (`WrongNoteModal`)**:
     - 시험 종료 후 오답이 있을 때 열리는 팝업창의 가장 아래(하단 푸터 영역)에 눈에 잘 띄는 안내 배너로 **`💡 오답공부가 필요 없다면 "닫기" 버튼을 누르시면 됩니다`** 문구를 표시합니다.
- **Visual Identity & Theme**:
  - 기존 인디고/슬레이트(`indigo-600`, `slate-800`) 및 다크 모드 테마와 완벽히 조화되는 버튼·배너 스타일을 유지합니다.

---

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: 시험 중 '재시험' 버튼의 위치와 레이아웃**
  - *Chosen Approach*: 시험 문제 카드 및 어원 프롬프트 버튼 아래의 하단 액션 바 우측에 고정 배치합니다.
  - *Why*: 사용자가 문제를 풀거나 채점 결과를 확인하는 시선 흐름의 오른쪽 아래에 항상 위치하여 언제든 1클릭으로 시험을 리셋할 수 있습니다.
- **Decision 2: 확인 창 없는 즉시 리셋**
  - *Chosen Approach*: `재시험` 클릭 시 `startExamSession()`을 즉시 호출하여 새로운 무작위 문항으로 1번부터 재시작합니다.
  - *Why*: 빠른 반복 학습을 원하는 사용자의 요청에 맞춰 불필요한 모달 단계를 제거했습니다.

### 4. Technical Architecture & Data Strategy

```
┌─────────────────────────────────────────────────────────────────┐
│                     실전 시험 화면 (ExamView)                    │
│                                                                 │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  문제 카드 + 객관식 보기 / 주관식 입력 + 어원 프롬프트     │  │
│  └───────────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────┐ ┌─────────────────┐  │
│  │       다음 문제 (Enter) (채점 후)      │ │  🔄 재시험 (우하단)│  │
│  └───────────────────────────────────────┘ └─────────────────┘  │
│                                                    │            │
│                                   클릭 시 즉시 startExamSession()│
└────────────────────────────────────────────────────┼────────────┘
                                                     ▼
┌─────────────────────────────────────────────────────────────────┐
│                  오답 노트 팝업 (WrongNoteModal)                 │
│                                                                 │
│  [오답 목록 / 오답 스피드 학습 / 오답 철자 학습]                 │
│  ─────────────────────────────────────────────────────────────  │
│  [오답 학습 버튼들]                              [닫기 (Esc)]   │
│  📢 "오답공부가 필요 없다면 "닫기" 버튼을 누르시면 됩니다"       │
└─────────────────────────────────────────────────────────────────┘
```

- **Interactive Component & State Mapping**:
  - `ExamView`의 `startExamSession` 함수를 재시험 버튼의 `onClick` 핸들러에 직접 연결하여, 클릭 즉시 `currentIdx = 0`, `totalScore = 0`, `wrongList = []`로 초기화하고 새로운 무작위 문제 배열(`questions`)을 생성합니다.
  - `WrongNoteModal`의 하단 푸터 가장 아래에 공지 문구 엘리먼트를 추가하여 라이트/다크 모드 모두에서 선명하게 보이도록 구성합니다.
