# 퀴즈 인터랙션 개선, 탭 자동 전환·셔플 및 효과음·폭죽 이펙트 구현 계획

스피드 퀴즈 보기의 **'터치하여 확인'** 클릭 버그를 수정하고, **스피드 40문항 완료 후 철자 탭 자동 이동**, **탭 클릭 시 단어 순서 무작위 셔플 새로고침**, 그리고 학습 몰입감을 높여주는 **정답/오답 효과음(띠링·띠딕·경쾌한 팡파르·환영 박수) 및 폭죽 연출**을 구현합니다.

### User Review & Critical Decisions

> [!IMPORTANT]
> 사용자 답변을 통해 확정된 세부 동작 사양입니다.

- **효과음 및 원어민 발음 재생 순서 (확정)**: 정답/오답 판정 즉시 효과음(띠링!, 띠딕!, 경쾌한 정답음)이 먼저 재생되고, 직후 스페인어 원어민 발음이 자연스럽게 이어서 재생됩니다. 또한 상단 헤더에 **효과음 켜기/끄기(Mute) 버튼**을 제공합니다.
- **철자·시험 탭 오답 효과음 적용 (확정)**: 스피드 탭뿐만 아니라 철자 탭과 실전 시험 탭에서도 오답 제출 시 동일하게 **"띠딕!"** 오답 효과음이 재생됩니다.

---

### 1. Overview & Core Concept

- **What It Does**:
  1. **보기 내 '터치하여 확인' 클릭 작동 수정**: 스피드 퀴즈(한➔스)에서 정답 확인 후 가려진 스페인어 보기(`터치하여 확인`)를 클릭하면 즉시 실제 스페인어 철자가 나타나도록 수정합니다.
  2. **스피드 ➔ 철자 자동 전환 & 철자 무한 반복**: 상위 공부 탭에서 스피드 퀴즈 40문제를 모두 풀고 마지막 문제에서 다음으로 넘어가면 **자동으로 철자 탭 1번 문제로 전환**되어 이어서 학습하며, 철자 탭 40문제를 다 풀면 **다시 철자 탭 1번 문제(새로 셔플된 상태)로 순환**합니다.
  3. **탭 클릭 시 즉시 셔플 새로고침**: 상단의 `스피드` 또는 `철자` 탭 버튼을 누를 때마다(이미 해당 탭에 있더라도) 문제 목록이 새로 섞여서 1번 문제부터 신선하게 시작됩니다.
  4. **맞춤형 사운드 & 폭죽 피드백**:
     - **스피드 정답**: 맑은 **"띠링!"** 효과음 재생
     - **스피드·철자·시험 오답**: 낮은 톤의 **"띠딕!"** 오답 효과음 재생
     - **철자 타이핑 정답**: "띠링!"보다 한층 더 경쾌한 3화음 **정답 차임벨 사운드** + 화면 중앙/입력창 주변 **작은 폭죽(Confetti)** 연출
     - **실전 시험 80점 이상 합격**: 결과 화면 진입 시 **환영의 박수 소리 + 팡파르** 재생 및 화면 전체 **큰 폭죽(Grand Fireworks)** 연출

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **스피드 퀴즈 보기 클릭 흐름**:
     - 채점 전 클릭 ➔ 해당 보기 선택 및 정오답 판정
     - 채점 후 정답 보기 내 `터치하여 확인` 클릭 ➔ 가려진 스페인어 단어가 즉시 공개됨 (보너스 철자 연습 전후 언제든 확인 가능)
  2. **연속 학습 흐름**:
     - `스피드 (40/40)` 완료 후 `다음 문제` 클릭 ➔ 자동으로 `철자 (1/40)` 탭으로 이동
     - `철자 (40/40)` 완료 후 `다음 문제` 클릭 ➔ 새로운 무작위 순서로 `철자 (1/40)` 첫 문제부터 재시작
     - 상단 `스피드` 또는 `철자` 탭 버튼 클릭 시 ➔ 언제든 단어 순서가 새로 섞여 1번부터 새로고침됨
  3. **시각·청각 피드백**:
     - 외부 오디오 파일 로딩 실패나 지연이 없도록 **Web Audio API** 기반의 고음질 신디사이저 사운드 엔진과 60fps 캔버스 파티클 폭죽 오버레이를 결합합니다.

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: 보기 버튼의 비활성화(`disabled`) 처리 개선**
  - *Chosen Approach*: 채점 완료(`answered === true`) 상태에서도 정답 보기의 `터치하여 확인` 영역은 클릭 이벤트를 받을 수 있도록 부모 버튼의 일괄 `disabled` 속성을 해제하고 상태별 클릭 핸들러로 분리합니다.
  - *Why*: 브라우저 기본 동작상 `<button disabled>` 내부의 자식 요소는 클릭 이벤트가 차단되므로, 이를 해결해 `터치하여 확인`이 즉시 반응하도록 만듭니다.
- **Decision 2: Web Audio API 기반 효과음 및 박수 사운드 생성**
  - *Chosen Approach*: 브라우저 내장 Web Audio API를 활용해 "띠링!", "띠딕!", "경쾌한 철자 정답음", "환영 박수 및 축하 화음"을 실시간 생성하고, 약 250~350ms 후 에콰도르 스페인어 발음(TTS)이 이어지도록 시퀀싱합니다.
  - *Why*: 네트워크 지연이나 외부 MP3 링크 깨짐 없이 모든 기기에서 즉각적이고 일관된 사운드를 보장합니다.

```
│                        상단 헤더 & 탭 네비게이션                      │
│  [🔊 효과음 ON/OFF]  [스피드 탭 (클릭 시 셔플)]  [철자 탭 (클릭 시 셔플)] │
└───────────────┬──────────────────────────┬───────────────────────────┘
                │                          │
                ▼                          ▼
┌───────────────────────────────┐  ┌───────────────────────────────────┐
│   스피드 퀴즈 (1~40번 문항)    │  │     철자 연습 (1~40번 문항)        │
│ • 정답: "띠링!" ➔ 스페인어 발음│  │ • 정답: 경쾌한 차임벨 + 작은 폭죽 │
│ • 오답: "띠딕!" ➔ 스페인어 발음│  │ • 오답: "띠딕!" ➔ 스페인어 발음   │
│ • 보기 [터치하여 확인] 즉시 공개│  │ • 40번 완료 시 ➔ 철자 1번 리셋     │

└───────────────────────────────┘
                │
                ▼
┌──────────────────────────────────────────────────────────────────────┐
│                        실전 시험 (ExamView)                          │
│ • 문항 오답 시: "띠딕!" 효과음                                       │
│ • 종료 시 80점 이상 달성: 환영 박수 소리 + 화면 전체 큰 폭죽 연출     │
└──────────────────────────────────────────────────────────────────────┘
```

- **Interactive Component & State Mapping**:
  - `shuffleSeed` 상태를 도입하여 상단 `스피드` 또는 `철자` 탭 클릭 시마다 시드 값을 증가시켜 문제 배열을 즉시 재셔플하고 `currentIdx = 0`으로 초기화합니다.
  - `QuizEngine`에 `onCompleteAllQuestions` 콜백을 연결하여, 상위 `스피드` 탭 완료 시 `activeTab`을 `'write'`로 전환하고, `철자` 탭 완료 시 새로운 셔플로 1번 문항부터 다시 시작합니다.
