# 스페인어 퇴근 단어 마스터 (1~30회차 600단어) 개선 및 다국어 단일 모드 전환 계획

기존 단일 HTML 기반의 600단어 학습 애플리케이션을 모던 React + TypeScript 아키텍처로 전면 고도화하며, 첫 화면 언어 선택을 통한 **한국어 / Español 100% 단일 언어 분리**, **어원·연상법 버튼 제거**, **라틴아메리카 에콰도르(`es-EC`) 발음 엔진 강화**, **집중공부 전용 퀴즈 및 전체 단어 검색**, **다크 모드**를 적용합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> **사용자 확인을 통해 확정된 핵심 설계 사항**
> - **언어 선택 및 상단 전환**: 앱 진입 시 첫 화면에서 `한국어` 또는 `Español`을 선택하며, 학습 중에도 상단 헤더의 언어 전환 버튼으로 즉시 언어를 바꿀 수 있습니다.
> - **단일 언어 완전 분리 (뜻풀이 포함)**:
>   - **한국어 모드**: 모든 인터페이스, 안내문, 버튼, 피드백이 100% 한국어로만 표시되며, 한국어 뜻풀이와 학습 단어를 매칭합니다.
>   - **Español 모드**: 인터페이스부터 600개 단어의 뜻풀이(스페인어 정의·유의어 설명)까지 한글이 단 한 글자도 섞이지 않은 **100% 순수 스페인어**로만 동작합니다.
> - **어원 및 연상법 완전 제거**: 학습 화면(스피드 퀴즈, 철자 연습)에서 집중도를 해치던 `어원(E)` 및 `연상법(M)` 버튼과 패널, 관련 단축키를 완전히 삭제하고 `이전(8)`, `정답확인(H)`, `다시 풀기(9)`, `발음 듣기(0)` 핵심 도구만 남깁니다.
> - **에콰도르(`es-EC`) 발음 최적화**: 모든 발음 듣기 기능은 스페인 본토(`es-ES`) 억양을 배제하고 라틴아메리카 **에콰도르(`es-EC`)** 및 안데스 권역(`es-CO`, `es-419`) 음성을 최우선으로 선택하여 또렷한 중남미 발음을 재생합니다.
> - **추가 편의 기능**: 다크 모드 테마 전환, 집중공부 폴더에 담긴 단어들로만 진행하는 전용 스피드·철자 퀴즈, 단어장 내 회차/전체 600단어 실시간 검색 필터를 제공합니다.

## 1. Overview & Core Concept

- **What It Does**: 1회차부터 30회차까지 총 600개의 필수 어휘를 5가지 모드(스피드 퀴즈, 철자 연습, 단어장, 집중공부, 누적 실전 시험)로 학습하고 80점 이상 달성 여부를 판정하는 체계적인 단어 마스터 웹 앱입니다.
- **Target Audience**: 한국어로 스페인어 어휘를 빠르게 암기하려는 학습자 및 스페인어 단일 언어 환경(Immersion)에서 어휘와 정의를 학습·시험하려는 사용자 모두를 지원합니다.
- **Key Value**: 어원·연상법 등 불필요한 부가 요소를 덜어내어 문제 풀이 속도와 직관성을 극대화하고, 집중공부 전용 퀴즈와 전체 검색으로 취약 단어를 완벽히 정복할 수 있습니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **첫 화면 언어 선택 (Language Gate)**: 앱 접속 시 세련된 인트로 화면에서 `한국어` 또는 `Español` 대형 카드를 선택합니다.
  2. **회차 선택 및 5대 학습 탭**: 1~30회차 드롭다운 및 이전/다음 버튼으로 회차를 이동하며, `스피드`, `철자`, `단어장`, `집중공부`, `시험` 탭을 오가며 학습합니다.
  3. **깔끔해진 학습 카드 도구 바**: 문제 카드 하단에는 `◀ 이전 (8)`, `💡 정답확인 (H)` 버튼과 상단 `🔊 발음 듣기 (0)`만 배치하여 시선 분산을 없앱니다.
  4. **집중공부 전용 퀴즈**: 퀴즈나 시험 중 체크(`C`)한 단어들이 모인 `집중공부` 탭에서 단어 목록 확인뿐만 아니라, 해당 단어들만 대상으로 `스피드 퀴즈`와 `철자 연습`을 즉시 실행할 수 있습니다.
  5. **단어장 실시간 검색 및 가림막**: 현재 회차(20단어) 또는 전체 회차(600단어) 범위에서 검색어로 단어를 즉시 찾고, 가림막 토글로 암기 상태를 점검합니다.

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 학습 집중도를 높이는 모던 에듀테크(EdTech) 인터페이스. 데스크톱에서는 2컬럼 확장 레이아웃(좌측 회차·진행률·집중공부 요약 사이드바 + 우측 메인 학습 스테이지)을 제공하고, 모바일에서는 한 손 엄지 조작에 최적화된 터치 레이아웃을 제공합니다.
  - *Color Palette & Mood*:
    - **Light Mode**: 깨끗한 오프화이트 캔버스(`#F8FAFC`), 화이트 카드 표면(`#FFFFFF`), 인디고 포인트(`#4F46E5`), 정답 에메랄드(`#10B981`), 오답 코럴 레드(`#EF4444`).
    - **Dark Mode**: 눈의 피로를 줄이는 딥 슬레이트 캔버스(`#0F172A`), 다크 카드 표면(`#1E293B`), 선명한 인디고 액센트(`#6366F1`), 고대비 텍스트(`#F8FAFC`).
  - *Typography & Hierarchy*: 디스플레이 및 헤드라인에는 가독성과 조형미가 뛰어난 산세리프 서체를 적용하고, 모든 점수·문항 번호·진행률 수치에는 고정폭 숫자(`tabular-nums`)를 적용해 흔들림 없는 정렬을 유지합니다.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 한국어 / Español 100% 단일 언어 데이터 구조**
  - *Chosen Approach*: 600개 전체 단어 데이터셋에 한국어 뜻(`ko`)과 함께 스페인어 단일 언어 정의(`esDef`: 쉬운 스페인어 뜻풀이 및 유의어)를 모두 내장합니다.
  - *Why*: 사용자가 `Español` 모드를 선택했을 때 한국어가 전혀 보이지 않으면서도, 단어의 정확한 의미와 스페인어 어휘 간 매칭(단어 ⇄ 스페인어 뜻풀이)을 통해 온전한 스페인어 학습 및 시험이 가능해집니다.
- **Decision 2: 에콰도르(`es-EC`) 음성 합성 우선순위 엔진**
  - *Chosen Approach*: 브라우저 `speechSynthesis`에서 `es-EC`(에콰도르) 로케일을 1순위로 탐색하고, 기기에 따라 `es-CO`(콜롬비아), `es-PE`(페루), `es-419`(라틴아메리카 공통) 순으로 폴백하며 `lang = 'es-EC'` 속성과 속도(`0.90`)를 고정합니다.
  - *Why*: 스페인 본토(`es-ES`)의 `z/c` 치간마찰음([θ]) 대신 중남미 에콰도르 특유의 또렷하고 부드러운 [s] 발음(Seseo)과 억양을 일관되게 제공하기 위함입니다.
- **Decision 3: 집중공부 폴더 전용 퀴즈 모드 통합**
  - *Chosen Approach*: 집중공부 탭 내부에 `목록 보기`, `스피드 퀴즈 풀기`, `철자 연습하기` 서브 모드를 탑재합니다.
  - *Why*: 오답이나 헷갈리는 단어를 모아두는 것에 그치지 않고, 모은 단어만 반복 테스트하여 완전 암기로 이어지게 합니다.

### Data Model & State
- **Vocabulary Item (`VocabWord`)**:
  - `id`: 고유 번호 (`round * 1000 + index`)
  - `round`: 회차 (`1` ~ `30`)
  - `es`: 스페인어 표제어 (성별 변화 `/a`, `/o` 포함)
  - `altEs`: 스페인어 정답 인정 변형 배열
  - `ko`: 한국어 뜻 (한국어 모드 전용)
  - `altKo`: 한국어 개별 정답 인정 토큰 배열
  - `esDef`: 스페인어 뜻풀이 및 핵심 유의어 (Español 모드 전용, 한글 완전 배제)
  - `altEsDef`: 스페인어 뜻풀이 정답 인정 키워드 배열
- **Persistent Storage (`localStorage`)**:
  - `es_master_lang`: 선택한 언어 (`ko` | `es`)
  - `es_master_theme`: 테마 설정 (`light` | `dark`)
  - `es_focus_ids_v3`: 집중공부 폴더 단어 ID 배열 (기존 데이터 호환 유지)
  - `es_round_scores`: 회차별 최고 시험 점수 및 통과 여부 기록

### Interactive Component & State Mapping
- **Language Gate & Switcher**: 첫 진입 시 언어 선택 모달/화면을 표시하며, 선택 즉시 전역 사전(`UI_TEXT[lang]`)과 문제 생성기가 해당 단일 언어로 렌더링됩니다.
- **Speed & Write Quiz Engine**: 어원(`E`)과 연상법(`M`) 핸들러를 제거하고, 숫자키 `1~4`(객관식 선택), `1~7`(철자 입력 시 `á, é, í, ó, ú, ñ, /` 자동 삽입), `8`(이전 문제), `9`(다시 풀기), `0`(에콰도르 발음 재생), `H`(정답 미리보기), `C`(집중공부 토글), `Enter`(제출 및 다음 이동) 단축키가 모든 입력 상태와 충돌 없이 작동합니다.
- **Focus Study Sub-Quiz**: 집중공부 폴더에 1개 이상의 단어가 있을 때 `집중공부 스피드 퀴즈` 및 `집중공부 철자 연습`을 활성화하여, 저장된 단어 풀 안에서만 문제를 출제하고 완료 시 성취 피드백을 제공합니다.
